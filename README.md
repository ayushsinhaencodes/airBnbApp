# 🏡 Airbnb Clone - Spring Boot

## 📌 Project Overview

This project is a backend application simulating an Airbnb-like platform where users can register, list properties, and book stays. It focuses on secure, scalable REST API design with real-world features like authentication and payment integration.

---

## 🚀 Tech Stack

* Java 21
* Spring Boot 3
* Spring Security (JWT Authentication)
* Spring Data JPA (Hibernate)
* PostgreSQL
* Stripe Payment Gateway
* ModelMapper
* Swagger / OpenAPI

---

## 🔥 Features

* User Registration & Login (JWT आधारित authentication)
* Property Listing & Management
* Booking System with status handling
* Guest Management for bookings
* Payment Integration using Stripe
* Global Exception Handling
* DTO-based architecture for clean API design

---

## 🔐 Security

* Implemented JWT-based authentication
* Role-based authorization
* Secure API endpoints

---

## 💳 Payment Integration

* Integrated Stripe API for handling booking payments

---

## 🧱 Project Structure

* Controller Layer → Handles API requests
* Service Layer → Business logic
* Repository Layer → Database interaction

---

## 📖 API Documentation

Swagger UI available for testing APIs.

---

## ⚙️ How to Run

1. Clone the repository
2. Configure PostgreSQL in `application.properties`
3. Run the application using:
   mvn spring-boot:run
